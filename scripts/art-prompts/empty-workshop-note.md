# A06 车间每日问题空状态

提示词版本：v1.0

用途：峰运通 Web 车间每日问题页面当天没有记录时的空状态插画
类型：透明背景纵向轻量插画，先在完全均匀的 #00FF00 背景上生成，便于本地抠图
主体：手机拍摄框、现场记录卡片、一个小型蓝青提示节点，表达可以开始上报
构图：1024×1024 中央偏下构图，纵向安全区充足，适合移动页面宽度 160～220px
风格：克制、专业、现场工作记录感，不画人物脸部，不画具体设备型号
配色：深海蓝、品牌蓝、品牌青、浅灰和少量暖灰
文字：无文字、无数字、无品牌、无水印
约束：背景必须完全均匀为 #00FF00；不生成中文说明、按钮、相机品牌和真实工厂标识；插画不能暗示错误

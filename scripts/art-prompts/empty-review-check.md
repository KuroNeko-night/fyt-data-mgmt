# A07 人工复核空状态

提示词版本：v1.0

用途：峰运通 Web 人工复核和任务中心待确认筛选无待办时的空状态插画
类型：透明背景方形轻量插画，先在完全均匀的 #00FF00 背景上生成，便于本地抠图
主体：一张带小型检查标记的业务纸张、一个闭合的蓝青信号节点
构图：1024×1024 居中构图，主体紧凑，四周透明安全边距
风格：安静、专业、有结束感，不使用夸张的大勾、不画奖杯、不暗示绩效
配色：品牌蓝、成功绿、深海蓝、白色和浅灰
文字：无文字、无数字、无 Logo、无水印
约束：背景必须完全均匀为 #00FF00；不出现人物、按钮、真实表格和庆祝装饰；失败或服务异常不应被表达为成功

# A02 工作台数据丝带

提示词版本：v1.0

用途：峰运通 Web 工作台和 Tauri 首页右上角主视觉
类型：透明背景抽象业务数据流插画，先在完全平整的 #00FF00 背景上生成，便于本地抠图
主体：三到五个抽象文件节点、表格纸片、数据丝带、圆形检查节点和输出文件节点
构图：1536×1024 横向构图，主体集中在画面中下部，四周保留透明安全边距，适合放在界面右上角
风格：精致的企业数据产品插画，纸张、透明片和细线结构结合，结构清晰、低饱和、无大面积阴影
配色：深海蓝、品牌蓝、品牌青、少量白色，不使用紫色、荧光绿和红色作为主体颜色
文字：无文字、无数字、无 Logo、无水印
约束：背景必须完全均匀为 #00FF00；不出现按钮、真实软件界面、人物和复杂投影；不要把主体画成具体产品截图

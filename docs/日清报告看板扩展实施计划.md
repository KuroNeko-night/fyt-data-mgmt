# 日清报告看板扩展实施计划

## 一、目标

用 Web 日清看板逐步替代《8月4日 日清报告.pptx》中的人工拼版，保留管理层熟悉的阅读顺序，同时把每日需要人工维护的内容变成可追踪、可审核、可导出的结构化数据。

## 二、PPT 结构审计

参考文件共 18 页，主要业务段落如下：

1. 参会人员及重大/升级事项；
2. 生产计划通报（计划/实际/差异、批次明细、月度订单台账、零星订单）；
3. 生产人员出勤；
4. 安全检查通报；
5. 过程指标通报（主料、辅材、重点专题问题跟踪）；
6. 当日问题通报（按问题表格和现场图片汇报）；
7. 往期会议待办；
8. 当日会议待办。

当前看板已覆盖“每日到料明细”和“现场问题（未分类汇报）”，本次扩展优先补齐管理层每日最常用的人工录入和结构化汇报链路。

## 三、数据模型

### 1. 日清人员主数据

- `daily_people`：姓名、人员类型（参会人员/生产人员）、所属单位或班组、班次、排序、启用状态；
- 管理员可以新增、停用、删除，删除前保留历史考勤快照；
- 人员名称与主数据库中的人员字段保持可扩展，不影响材料主数据。

### 2. 每日考勤

- `daily_attendance`：业务日期、人员、是否出勤、考勤原因、最后修改人和时间；
- 默认按启用人员生成当天记录，开关打开表示出勤，关闭表示缺勤；
- 允许额外标记“迟到、请假、出差”等状态，原因文本始终可编辑；
- 参会人员和生产人员在同一选项卡中分区展示。

### 3. 重点事项与通报

- `daily_brief_items`：日期、类别（重大/升级、通报、当日待办、往期待办、过程指标、安全检查）、单位、责任人、标题、描述、期限、进展、状态；
- 管理员可以新增、编辑、完成、撤销；
- 管理层页面按类别聚合，重大/升级事项与通报在首屏并列显示。

### 4. 现场问题分类

- 给 `workshop_issues` 增加 `category`、`severity` 字段；
- 默认分类：质量、设备、物料、工艺、包装、安全、人员、其他；
- 看板按分类统计数量、负责人和图片数；
- 导出时保留问题清单、分类汇总、图片附件三张工作表，首张清单为每条问题适配多张缩略图，附件表逐图记录。

### 5. 生产计划上传

- `daily_production_plans`：日期、原始文件、上传者、上传时间、解析摘要、预览行；
- 仅管理员可上传/替换/删除；
- 页面单独选项卡，支持上传 Excel、展示文件元数据和关键数字，保留原始文件下载；
- 解析器只做安全的表头/行预览，不覆盖业务模块已有的生产计划处理逻辑。

## 四、接口约定

- `GET /api/daily-report?date=YYYY-MM-DD`：返回到料、现场问题、考勤、重点事项、分类汇总、生产计划摘要；
- `GET /api/daily-report/production-plans?date=...`：管理员查看当天上传计划；
- `POST /api/admin/daily-attendance`：批量保存当天考勤；
- `GET/POST/PATCH/DELETE /api/admin/daily-people`：维护日清人员；
- `GET/POST/PATCH/DELETE /api/admin/daily-brief-items`：维护重点事项/通报/待办；
- `POST /api/admin/daily-production-plans`：上传生产计划；
- `DELETE /api/admin/daily-production-plans/{id}`：移入回收站；
- `/api/workshop/issues` 新增 `category`、`severity` 字段，旧客户端不传时自动使用“其他/一般”。

所有写接口均要求管理员权限，全部写入审计日志；报告查询允许管理员查看全账号数据，普通账号继续保持原有数据隔离。

## 五、前端信息架构

日清看板采用选项卡：

- 总览：到料完成率、缺料详情、问题分类、重点事项/通报；
- 考勤：参会人员和生产人员两个分区，开关式考勤、原因、批量保存；
- 现场问题：按分类/严重程度汇总，支持展开问题和多图预览；
- 生产计划：上传、预览、下载和删除计划文件；
- 待办与指标：过程指标、安全检查、当日/往期会议待办。

移动端使用横向滚动的选项卡、纵向数据列表和大号编辑抽屉；桌面端保留宽表和并列摘要。所有动画只用于选项卡切换、数据刷新和详情展开，并遵守 `prefers-reduced-motion`。

## 六、执行顺序

1. 数据库迁移、权限和审计；
2. 日清人员与考勤接口及前端；
3. 重点事项/通报/待办接口及前端；
4. 现场问题分类、汇总和多图导出；
5. 生产计划上传、解析预览和下载；
6. 合并日清快照与 Excel 导出；
7. Python、Web 构建、接口回归和移动端渲染验收；
8. 同步更新项目全景文档。

## 七、验收标准

- 管理员可维护人员、考勤、重点事项、通报和生产计划；
- 当天看板无需打开 PPT 即能完成同样的信息核对；
- 每条问题可按分类统计，导出 Excel 中每张图片均可见且不挤压文字；
- 历史日期只读或按权限编辑，旧数据不因迁移丢失；
- 普通账号无法调用管理员写接口；
- 全量单元测试、Web/Tauri 构建通过，移动端无横向溢出和不可点击控件。

# 峰运通数据管理系统 · AI 协作排错指南

> 这是一份“卡住时再打开”的兜底文档，写给没有技术背景的维护人员。
> 它不代替《运维部署完全指南》，而是教你怎样把当前情况安全、完整地告诉 AI，让 AI 一步一步陪你排查。
> 在向AI提问前，先把运维部署完全指南作为附件发送给AI

## 先记住：卡住时不要继续往下做

遇到报错、页面和文档不一致、命令长时间没有变化，先做下面四件事：

1. **停在当前小节**，不要连续重试，也不要继续执行后面的命令。
2. 记下自己正在做的**章节编号和标题**，例如“第 6.5 节：写 Caddy 配置”。
3. 保存错误画面：终端复制“第一条错误到最后一行”，网页可以截图。
4. 打开一个新的 AI 对话，先发送下面的“通用开始提示词”，再把经过遮挡的信息发给 AI。

如果操作可能影响数据，宁可先停下，也不要凭感觉删除文件、重新安装或恢复备份。

<a id="ai-start"></a>

## 直接复制：通用开始提示词

把下面整段复制给 AI，再替换方括号里的内容。不知道的地方写“我不知道”，不要猜。

```text
你现在是“峰运通数据管理系统”的部署协作助手。我没有技术背景，请使用中文，一次只带我做一个小步骤。

我正在按照《峰运通数据管理系统·运维部署完全指南》操作。
当前章节：[例如：第 5.4 节 执行一键安装]
操作位置：[Windows PowerShell / Linux 服务器终端 / 阿里云控制台 / Cloudflare 网页]
我的目标：[一句话说明想完成什么]
我已经完成：[只写确定完成的步骤]
当前现象：[页面显示什么，或命令停在哪里]
错误原文：[粘贴从第一条错误到最后一行；没有就写“没有明确错误”]
我最近执行的命令：[粘贴命令，但删除密码、Token、私钥和 Cookie]
系统或软件版本：[不知道就写“请教我用只读命令查看”]

请严格遵守以下方式帮助我：
1. 先判断还缺哪些信息，只给我一条安全、只读的检查命令；不要一次给很多命令。
2. 每条命令都说明“在哪里执行”“是否会修改系统”“正常时应看到什么”。
3. 等我贴回结果后，再给下一步，不要提前假设检查结果。
4. 不要让我删除、覆盖、移动或修改 /var/lib/fyt-web，也不要重建数据库或账号。
5. 涉及停止服务、修改配置、权限、证书、升级或恢复时，先说明影响和回退方法。
6. 不要要求我发送密码、私钥、Token、Cookie、完整环境变量文件或真实业务数据。
7. 如果你不能确定命令适用于我的系统，请先让我查看系统版本，不要猜。
8. 如果建议与项目指南冲突，先指出冲突并停止，等我找项目维护人员确认。
```

这段提示词最重要的作用，是让 AI **先检查、后修复，一次一步**。零基础用户最容易被“一口气运行十条命令”带偏，所以不要省略这些约束。

<a id="ai-safe-share"></a>

## 发给 AI 之前，先遮住这些内容

### 绝对不能发送

- 密码、验证码、密码管理器画面。
- `BEGIN PRIVATE KEY` 到 `END PRIVATE KEY` 之间的全部内容。
- Cloudflare API Token、Tunnel Token、GitHub Token、登录 Cookie、会话值。
- `/etc/fyt-web/fyt-web.env` 的完整内容。
- 数据库文件、完整备份包、真实业务表格和客户资料。

### 可以发送，但建议替换

- 域名替换成 `fyt.example.com`。
- 公网 IP 替换成 `203.0.113.10`。
- 用户名、邮箱和公司名用 `用户A`、`example@example.com` 代替。
- 文件名涉及客户或物料时，改成 `测试文件.xlsx`。

### 通常可以原样发送

- `systemctl status`、`journalctl` 的报错，但先快速检查是否夹带环境变量或访问令牌。
- `cat /etc/os-release`、`python3 --version`、`caddy version`。
- `curl .../api/health` 返回的健康状态。
- `sha256sum` 校验结果、端口监听结果。

Cloudflare Origin CA 的**证书**不是私钥，但零基础用户很容易把两者弄混。最安全的做法是：证书正文也不发，只发送域名、有效期和检查命令的结果。

<a id="ai-how-to-copy-error"></a>

## 不知道该发什么时，按这个最小清单收集

先把通用开始提示词发给 AI，再根据 AI 的要求逐项补充。通常只需要：

1. 当前指南章节，例如“第 7.3 节”。
2. 正在操作的位置，例如“阿里云服务器的 Workbench 终端”。
3. 最近执行的**一条**命令。
4. 从第一条错误到最后一行的完整文字。
5. 出错前最后一次成功的检查结果。
6. 是否已经有真实用户和数据，回答“有”或“没有”即可。

只有截图、没有文字时，可以对 AI 说：

```text
我只能提供截图。请先逐行读取截图中的错误，不要根据画面猜测；请告诉我还需要复制哪一段文字。截图中如果疑似包含密码、Token、私钥或业务数据，请先提醒我遮挡，不要复述敏感内容。
```

<a id="ai-understand-guide"></a>

## 0. 看不懂路线、名词或架构

**常见情况：**不知道该从哪一段开始；分不清服务器、域名、DNS、Caddy；不知道命令应在自己电脑还是服务器执行。

起始提示词：

```text
我正在阅读峰运通运维指南，但不知道应该从哪一段开始。我的现状是：[已经有/没有域名]、[已经有/没有服务器]、[已经有/没有部署包]、[系统是否已经能在服务器本机打开]。请先用不超过五句话判断我的起点，再只告诉我应该进入哪个章节。不要先给安装命令。
```

如果只是看不懂一个词：

```text
请用日常生活中的比喻解释“[词语]”，并说明它在峰运通部署链路中的上一步和下一步。不要给我额外配置步骤。
```

<a id="ai-build-env"></a>

## 1.1 打包电脑、Python、Node.js、源码或 PowerShell 有问题

**常见情况：**找不到下载按钮；`py`、`node` 或 `npm` 提示不是命令；源码解压后目录不对；PowerShell 无法进入目录。

起始提示词：

```text
我在 Windows 电脑准备峰运通打包环境，卡在第 [1.1.1/1.1.2/1.1.3/1.1.4] 节。失败的命令和输出如下：[粘贴]。请先判断是软件没安装、终端没重新打开、PATH 没生效，还是目录不对。只给我一个不会修改项目文件的检查步骤。
```

看到“不是内部或外部命令”“无法将……识别为 cmdlet”时，把**完整那一行**发给 AI，不要只写“找不到”。

## 1.2 安装项目依赖失败

起始提示词：

```text
我在第 1.2 节安装峰运通项目依赖。最后一条成功命令是：[命令]；失败命令是：[命令]；完整错误是：[错误]。请先区分这是 PowerShell 执行策略、Python 虚拟环境、npm 依赖锁定还是网络问题。不要让我删除 lock 文件、node_modules 或 .venv，除非先解释原因和重建影响。
```

起始提示词：

```text

```

<a id="ai-nameserver"></a>

<a id="ai-security-group"></a>

## 4.1～4.3 不会设置安全组

**常见情况：**分不清入方向和出方向；不知道 Cloudflare IP 段怎么填；误开放 8787；规则冲突。

起始提示词：

```text
我在第 4 段配置阿里云安全组，采用“Cloudflare 橙色云 + Caddy”的传统方案。请根据我列出的现有规则逐条检查，不要让我直接删除规则。目标是：22 仅允许我的管理来源；80/443 只允许 Cloudflare 官方 IP 段；8787 不对公网开放；出方向满足 DNS、HTTPS 和系统更新。现有规则：[逐行列出协议、端口、来源/目标、允许或拒绝]
```

如果 AI 建议把所有入方向端口永久设为 `0.0.0.0/0`，不要执行，先找项目维护人员复核。

**常见情况：**依赖下载很慢；创建 `.venv` 失败；服务注册失败；安装完成但忘记保存一次性密码。

若屏幕里曾显示随机管理员密码，不要把密码发给 AI。只说“我已保存”或“我没有保存”。

## AI 给出命令后，执行前做一次“安全复述”

如果你看不懂 AI 给的命令，先不要执行。把下面这段发回同一个对话：

```text
在我执行前，请用表格解释这条命令：
1. 在哪里执行；
2. 会读取什么；
3. 会修改、覆盖、删除或停止什么；
4. 正常输出是什么；
5. 失败时怎么停下和回退；
6. 是否会影响 /var/lib/fyt-web、现有账号、上传文件或在线用户。

如果这条命令不是只读命令，请先给我对应的只读检查和备份步骤。
```

下面这些情况必须暂停，找项目维护人员确认：

- AI 要求删除、清空、重建或覆盖 `/var/lib/fyt-web`。
- AI 要求把真实私钥、密码、Token、Cookie、数据库或备份文件发给它。
- AI 要求永久关闭防火墙、把所有端口向 `0.0.0.0/0` 开放，或公开 8787。
- AI 要求通过降低到 `Flexible`、关闭证书验证等方式长期绕过 HTTPS 错误。
- AI 要求从不明网站下载可执行文件，或直接运行看不懂的网络脚本。
- AI 建议和《运维部署完全指南》或项目维护人员给出的要求相冲突。
